# Open Decisions

Central index for genuinely unresolved SwifWeb architecture choices.

No active architecture decision is recorded.

## Record Format

When a real unresolved choice appears, record:

- **Decision ID**
- **Owning architecture chunk**
- **Question**
- **Why it matters**
- **Blocking status**
- **Resolution timing**

When resolved, move the durable rule into exactly one architecture owner and remove the decision entry. Do not use this file for feature ideas, implementation tasks, or settled rules.
